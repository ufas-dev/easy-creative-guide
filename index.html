第 0 部　はじめに

画面全体マップ

本日ご説明する機能は、大きく4つのグループに分かれます。それぞれ何ができて、何が楽になるかをご紹介します。
3 / 46
商品の一括編集・予約
商品情報／バナー予約／共通説明文（大）予約
  • 数百商品の情報を、Excel1枚で一括更新。1商品ずつ画面を開く必要がありません
  • セール開始の深夜0時でも、予約しておけば自動で切り替わります
  • バナー・共通説明文（大）も同じ仕組みで予約できます
ABテスト
サムネイル／商品名／説明文／商品画像ギャラリー／商品動画
  • 「どちらが売れるか」を実データで判定。感覚での判断から卒業できます
  • 楽天の商品アナリティクス・RPPからKPIを自動取得。集計作業は発生しません
  • 勝った方を自動反映。テストをやりっぱなしにしません
クリエイティブ自動生成
AI画像生成／LP生成／コラム記事／画像alt自動入力
  • サムネイル・バナーをAIが数分で生成。外注の待ち時間がなくなります
  • 縦長LPも、商品情報を入力するだけで1本まるごと生成できます
  • 生成した画像は、そのままABテストのB案として使えます
ヒートマップ
スクロール到達率の可視化
  • 商品ページのどこまで読まれているかを数値で可視化します
  • 「読まれていない位置」に置かれた訴求を発見できます
  • ABテストで何を変えるべきか、仮説の根拠になります
第 0 部　はじめに

「作る → 試す → 分析する → 改善する」1本のサイクルで完結

制作・反映・計測・改善が別々のツールに分かれていないので、データを持ち出す手間がありません。
4 / 46

このサイクルの価値

ツールをまたがない作成・反映・計測・改善が同じ画面。画像やデータの持ち出しが不要です。
作ったものをそのままテストに使えるABテストの登録画面から、AIで作った画像をそのままB案にできます。ダウンロードや移し替え、規定に合わせた作り直しが要りません。
回すほど精度が上がる終了したテストはAIが振り返り、次に何を試すべきかを提案します。
